音频去缝器 / Gap Remover

删掉录音里的无声空白，紧成一条不留空的 MP3。

🔒 全程本地处理，音频不上传任何服务器 · 断网可用
🎧
把音频文件拖到这里，或
MP3 / WAV / M4A / AAC / OGG / FLAC / MP4 音轨（能解多少取决于浏览器）· 支持多选，拖进来就开始处理
预设：
自动模式：底下 5% 当底噪、90% 当人声，取中间偏低处。
低于这条线的声音算静音。调高删得更多，调低更保守。
短于它的停顿不动 —— 说话的自然换气别切。
剪切后每两句话之间留多久。0 = 完全贴死，可能听感发赶。
剪切处做淡入淡出，防止「啪」的爆音。
纯前端实现：Web Audio 解码 → 分帧 RMS 找静音 → 拼接 → lamejs 编码 MP3。
长音频编码要等一会儿（1 小时音频大约 3～8 分钟，看机器），进度条会走，编码期间别刷新页面。
